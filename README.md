# 守夜 NIGHTWATCH

一个开始很像正经生意的网站。

它在卖家用摄像头：客厅、厨房、门口，一个普通的下午，一只睡着的狗。你要往下滚很久，才会发现它卖的不是这个。

---

## 结构

| 段落 | 内容 |
| --- | --- |
| 首屏 | 一台摄像机的实时画面，可以切换上午 / 下午 / 傍晚 |
| 它今天看见的 | 三件小事：妈包了饺子、狗睡了十六个小时、孩子四点二十到家 |
| 一天 | 同一天里的四个时刻 |
| 三分钟 | 安装说明 |
| 故事 | 你在另一个城市，晚上十点，酒店房间 |
| 价格 | 一台，或者三台 |
| **现在** | 同一台摄像机，同一间客厅。狗不在毯子上。时间条自己长出一格：**23:40** |
| 常见问题 | 网站继续用售后的语气说话 |
| 终章 | 那个人一步一步走到镜头前 |

## 技术

纯静态，没有构建、没有依赖、没有外部请求。

- **画面**全部是 canvas 程序化绘制：一间客厅，四束光（上午 / 下午 / 傍晚 / 夜里），一只趴着的狗，一个站着的人。
- **声音**全部是 WebAudio 合成：房间底噪、心跳、尖啸。跳杀那一下是四个失谐锯齿 → 硬削波 → 幅度量化 → 环形调制 → 三次断续重来。
- 滚动驱动：`progressOf()` 把每个段落换算成 0–1，画面和文案都挂在上面。

## 运行

```bash
# 直接打开，或者
python -m http.server 8000
```

**进去先点一下页面**——浏览器的自动播放策略要求一次真实交互才给声音。如果到了夜里还没声音，右下角会出现「♪ 开启声音」。

## 注意

页面里有突发强音和闪烁画面。戴耳机，别外放。

## 调试参数

| 参数 | 作用 |
| --- | --- |
| `?t=0/1/2` | 首屏切到上午 / 下午 / 傍晚 |
| `?nowp=0.6` | 直接定位「现在」这一段的进度 |
| `?finq=0.85` | 直接定位终章的进度 |
| `?flat` | 摊平 sticky 段落，方便截图 |
| `?shift=1200` | 整体上移，无头浏览器截图用 |
